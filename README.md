# TEAM BLOG

情報サービス課「TEAM BLOG」の運用・管理用リポジトリです。

TEAM BLOGでは、情報サービス課のメンバーが note・Qiita・Zenn・個人サイト等で公開した技術やそれにまつわる動向についての記事を集約し、情報サービス課Webサイトで紹介します。

## Purpose

TEAM BLOGには、以下の目的があります。

- 情報サービス課の技術力・取り組みの発信
- メンバー同士の知識・経験の共有
- アウトプットを通じた技術力・発信力の向上
- 個人に残る技術記事・ポートフォリオの形成
- 一般就労やキャリア形成における実績の可視化

## Documents

TEAM BLOGへの参加・記事掲載については、以下を確認してください。

- [`RULES.md`](./RULES.md) - 参加方法・記事掲載フロー
- [`POLICY.md`](./POLICY.md) - 掲載ポリシー・禁止事項

## Media

以下のような外部メディアを利用できます。

- note
- Qiita
- Zenn
- 個人サイト・個人ブログ
- その他、掲載に適したWebメディア

詳細については `RULES.md` および `POLICY.md` を確認してください。
